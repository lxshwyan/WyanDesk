# WyanDesk 扩展商店提交指南

本文档是 Chrome Web Store 和 Microsoft Edge Add-ons 的可复用提交材料。实际上架需要对应商店的开发者账号，不在代码构建和自动化范围内。

本轮扩展版本为 0.5.0，包含统一搜索、稍后阅读与桌面窗口入口。正式提交商店前须人工验收真实扩展权限和窗口恢复，不能将开发合成数据截图作为商店实测证据。

## 商店文案

- 名称：微言桌面 WyanDesk
- 简短说明：把微言桌面设为新标签页，快速收藏网页，批量整理和打开网站组合。
- 详细说明：WyanDesk 是本地优先的浏览器桌面，集中管理常用网站、任务、日程、便签和专注计时。扩展可将当前页存为网站、任务、便签或稍后阅读，也可通过右键主动保存选中文字与来源，并添加自己的备注。统一搜索覆盖已有桌面内容，按需授权后还能切换当前窗口的标签。扩展可把当前窗口批量加入新建或已有网站组合，自动过滤重复网址，并一键打开已保存组合。同时保留最多 20 个本机窗口快照，主动保存、不自动关闭网页，在新窗口恢复；新保存快照最多 200 个普通网页，不保存表单或登录状态。支持直接导入/导出浏览器书签。未登录也能使用，数据默认留在浏览器。
- 分类：Productivity（生产力）
- 官网：`https://desk.wyanhub.com/`
- 隐私说明：发布 `docs/PRIVACY.md` 的站点版本，提交时填写可公开访问的 HTTPS URL。

## 权限解释

| 权限 | 类型 | 用途与触发时机 |
| --- | --- | --- |
| `storage` | 必需 | 在扩展本地保存桌面状态摘要、待处理收藏、最多 20 个窗口会话和用户主动授权后的 Desk 专用令牌。 |
| `activeTab` | 必需 | 仅在用户点击“收藏当前网页/保存为任务/便签/稍后读”时读取当前页标题和 URL。 |
| `identity` | 必需 | 仅在用户点击“登录并同步”时打开 WyanHub 授权窗口，并安全接收一次性登录回调。 |
| `contextMenus` | 必需（0.4.10 新增） | 用户在普通网页或链接上右键后才收藏；主动选择“保存选中文字”时仅接收浏览器提供的选文，最多 2000 字符，忽略可编辑表单。不会主动读取整页正文或浏览历史。 |
| `https://wyanhub.com/*` | 必需主机 | 只用于交换和撤销 Desk 专用令牌；不读取网站 Cookie。 |
| `https://desk.wyanhub.com/*` | 必需主机 | 只用于读取和保存当前账号的云端桌面、历史版本和用户主动填写的反馈。 |
| `tabs` | 可选 | 仅在用户搜索已打开标签、批量保存或恢复窗口时申请；搜索和保存只查询当前窗口的普通网页，读取标题、URL、顺序和固定状态。恢复使用本机快照，在新窗口打开；打开已保存组合使用扩展本地摘要。不会扫描浏览历史或其他窗口。 |
| `bookmarks` | 可选 | 仅在用户选择直接导入或导出浏览器书签时申请。 |

扩展不声明全站主机权限或内容脚本，不执行远程代码，也不申请 `cookies` 权限。v0.4.10 要求 Chrome/Edge 116+，使用事件型 MV3 service worker 维护右键菜单、串行写入队列与保存回执；不做定时浏览历史扫描。它只查询自己的扩展页面上下文，必要时打开后台桌面页处理用户提交的收藏。Desk 专用令牌最长 30 天、服务端只保存哈希，并由 WyanHub 网关限制为桌面同步用途。

## 审核测试路径

1. 安装后打开新标签页，确认 WyanDesk 可在未登录状态使用。
2. 打开任意 HTTPS 页面，点击扩展，分别将页面保存为网站、任务和便签；回到新标签页验证内容。
3. 选择“新建网站组合”并保存当前窗口，同意可选 `tabs` 权限；再将其他窗口批量加入该组合，确认重复网址未被重复收藏。
4. 在扩展中选择已有组合并点击“打开该组合”，确认网页在当前窗口以后台标签页打开；关闭测试窗口后验证本地会话仍可恢复。
5. 点击导入或导出书签，验证只在该操作中请求可选 `bookmarks` 权限。
6. 拒绝任一可选权限，验证应用显示错误提示且本地桌面仍然可用。
7. 在新标签页点击“登录并同步”，确认浏览器显示 WyanHub 授权页；允许后验证账号名称、云端状态和自动保存，退出后验证扩展恢复本地模式。
8. v0.4.10：在页面和链接上分别右键，选择不同桌面分类，验证目标记忆、工具栏结果提示、无桌面页时的后台打开和处理；浏览器内部页不支持收藏。
9. v0.4.10：选择书签文件夹，分别导入所选分类/按原文件夹归类；确认预览数量、已有站点不移动、拒绝权限无读取、重复和非网页跳过、大于 5000 条时分文件夹处理。
10. v0.5.0：将页面加入稍后读，再通过右键保存选中文字；验证来源、2000 字符上限、可编辑区域不收集、重复收藏不产生重复项，以及已读资料重新收藏后恢复未读并保留备注。
11. v0.5.0：在桌面搜索任务正文、便签、阅读摘录和备注，点击后定位原内容；长结果列表用方向键选择时始终可见。点击“搜索已打开标签”后才请求可选权限，拒绝后不读取；允许后只搜索当前窗口，点击现有标签不会另开重复页，已关闭的标签显示错误。
12. v0.5.0：展开“继续上次工作”，命名并保存当前窗口，确认不自动关闭；恢复旧版快照和新版快照时新开窗口，检查固定/活动标签及部分失败反馈。拒绝权限、超过 200 个网页及本地保存失败时均有提示；确认快照不进入账号同步或桌面备份。

## 打包与提交前检查

```bash
npm ci
npm test
npm run typecheck
npm run package:extension
unzip -t public/downloads/wyandesk-extension.zip
(cd public/downloads && shasum -a 256 -c wyandesk-extension.zip.sha256)
```

`package:extension` 会校验 Manifest V3、版本号、权限与两个精确主机白名单、禁止内容脚本，并检查 HTML 未引用远程脚本。最终产物为：

- `public/downloads/wyandesk-extension.zip`
- `public/downloads/wyandesk-extension.zip.sha256`

商店审核完成前，官网 `https://desk.wyanhub.com/downloads/wyandesk-extension.zip` 作为测试用户的主下载地址。“桌面设置”首页顶部直接展示 Chrome / Edge 扩展下载和校验入口，安装与更新步骤在同一卡片内展开。手动安装包不会获得商店自动更新能力；每次发布都必须重新生成 ZIP 与校验文件并核对版本一致。

提交前还需人工确认：开发者账号、可公开隐私 URL、商店当前要求的截图、图标/宣传图、版本更新说明和联系邮箱。本仓库不保存商店密码或付款信息。
