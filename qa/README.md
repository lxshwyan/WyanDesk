# 桌面效率增强：本地验收

本目录是 Vite 开发夹具，不属于正常 `index.html` 构建入口，也不复制到官网 `public` 或扩展下载包。所有条目均为合成数据；窗口保存与恢复使用明确注入的模拟适配器，不读取、打开或关闭真实浏览器标签。

启动 `npm run dev`，以终端实际端口访问 `/qa/efficiency.html`：

- `?mode=reading`：来源、摘录、备注、阅读状态和移入目标。
- `?mode=search`：已有任务、便签与阅读资料的混合搜索结果。
- `?mode=search-long`：20 条合成匹配，最多显示 14 条，用于检查键盘选择和列表滚动。
- `?mode=continue`：默认折叠的本机窗口入口及模拟保存/恢复。
- `?mode=matrix`：三个 390×844 iframe，检查手机阅读、窗口入口和搜索。

## 2026-10-23 验证记录

- TypeScript、56 文件/224 项测试、网站/扩展构建、SEO、PWA 和 MV3 权限白名单校验通过；保留现有主包大于 500 kB 的构建提醒，没有抬高阈值。
- 本地真实 App 页面验证：任务搜索定位；添加阅读来源、备注、已读/未读筛选；搜索备注后定位原条目；未读首页仅显示紧凑入口。
- `search-long` 从首项连续按 13 次下方向键：第 14 项完整可见，`scrollTop=432`，选中项与输入框 `aria-activedescendant` 一致。
- 桌面与手机截图在本机 `.impeccable/review/efficiency-*.png`，仅用于组件布局验收，不是生产状态、真实权限授权或实际窗口恢复的证明。一次检测包含既有全局样式建议且输出过大，不声称全站检测零问题；独立审查唯一修复项为搜索键盘滚动与选项关联，修复复验裁定 `ship`。
